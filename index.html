Checking notification support…

Local-only limitation: without a push server, reminders are checked when the app is open or returns to the foreground. The app cannot reliably wake itself from a fully closed/suspended state at a scheduled time.

Create and edit individual reminders under More → Reminders. This section controls the iPhone notification permission.

YOUR DATA

Export / import

The exported trip file includes itinerary, budget setup, expenses and trip-tool metadata. When you import an update to the same trip, this device keeps its existing budget, exchange rates and expense history. Local PDF/image attachments in the document vault are not embedded in the export.

Import using a share link Paste a Travel Planner Full Trip or Itinerary share link.

RESET

Leave this trip

Export the trip first if you want to keep a copy. This returns the app to the Create / Import screen.

Privacy: No account, advertising, analytics or cloud database is used. Your trip stays in this browser unless you export it yourself.
